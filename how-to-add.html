Catalog / How to add entries

Contributing to the archive

Add a Beyblade entry

The catalog data lives in one file. Each Beyblade gets its own URL and dedicated page; the era breadcrumb takes readers back to that era's catalog.

  1. Open the shared catalog data

    Edit catalog-data.js in the repository. All Beyblade entries are inside the beys array.

  2. Add your photos to the repository

    Create a folder such as images/dragoon-storm/ and put your image files there. Use WebP for smaller downloads, clear filenames, and consistent capitalization; GitHub Pages paths are case-sensitive. Prefer photos you took or have permission to publish.

  3. Add one record per Beyblade

    Copy this object into beys, change the values, and keep the commas between neighboring objects. The era value must match an era's id listed at the top of the file.

    {
  id: "dragoon-storm-105fs",
  era: "metal-fusion",
  name: "Dragoon Storm",
  combo: "105FS",
  status: "In progress",
  image: "images/dragoon-storm/assembled.webp",
  imageAlt: "Dragoon Storm 105FS, top view",
  summary: "Short overview of what has been researched.",
  observations: []
}

    Make every id unique. It becomes the entry link, for example bey.html?id=dragoon-storm-105fs.

  4. Add individual part notes and visual references

    Each observation displays a midfake example beside a genuine reference. Add both image paths to show a side-by-side comparison; either side can stay empty until you have a verified photo. Click any added photo, including the Beyblade's main photo, to open it full-size.

    observations: [
  {
    component: "Facebolt code",
    note: "Describe what is visible and where the comparison comes from.",
    midfakeImage: "images/dragoon-storm/midfake-facebolt.webp",
    midfakeImageAlt: "Close-up of the facebolt on the midfake example",
    genuineImage: "images/dragoon-storm/genuine-facebolt.webp",
    genuineImageAlt: "Close-up of the facebolt on a genuine reference",
    sourceLabel: "Reference source",
    sourceUrl: "https://example.com/reference",
    sourceLabel2: "Second reference",
    sourceUrl2: "https://example.com/another-reference"
  }
]
  5. Save and publish

    Save the changed data file and add the image files to the repository. Once the GitHub Pages update is published, the entry appears in its era and opens on a separate page with Home → Era → Beyblade breadcrumbs.

Good research practice: distinguish direct observations from conclusions, link the original source, and compare more than one feature. Avoid presenting a single clue as a guaranteed authenticity test.
